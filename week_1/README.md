# CLI Grade Calculator

A simple **Command-Line Interface (CLI) Grade Calculator** built using Python as part of the **Week 1 Mini Project**.

This project demonstrates core Python fundamentals including **functions, loops, dictionaries, conditional statements, and user input**.

## 📌 Project Overview

The CLI Grade Calculator accepts student names and marks from the user, stores the information in a dictionary, calculates the corresponding grade, and displays the results.

## 🎯 Objectives

* Practice Python functions
* Use loops for repetitive operations
* Understand and use dictionaries
* Apply conditional statements
* Work with user input
* Build a simple command-line application

## 🛠️ Technologies Used

* **Python 3**

## ⚙️ How It Works

1. The program asks for the number of students.
2. It takes each student's name and marks as input.
3. The student information is stored in a dictionary.
4. A function determines the grade based on the marks.
5. The program displays each student's name, marks, and grade.

## 📊 Grading Criteria

|    Marks | Grade |
| -------: | :---: |
|   90–100 |   A   |
|    75–89 |   B   |
|    60–74 |   C   |
| Below 60 |   D   |

## ▶️ How to Run

Make sure Python 3 is installed on your system.

Run the following command in the terminal:

```bash
python grade_calculator.py
```

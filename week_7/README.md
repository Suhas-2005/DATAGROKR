
# Week 7 - Task Manager with Gitflow

## Project Overview
A simple Task Manager built using HTML, CSS, and JavaScript. This project demonstrates Git and GitHub version control workflows.

## Features
- Add tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Validate empty input

## Technologies
- HTML
- CSS
- JavaScript
- Git and GitHub

## Git Concepts Practiced
- Repository initialization
- Branching and merging
- Merge conflict resolution
- Pull Requests
- Git stash, rebase, and cherry-pick
- Release and hotfix workflow
- Pre-commit hooks
- GitHub Actions

## How to Run
Open `index.html` in a web browser.

## Project Structure
- `index.html` - Page structure
- `style.css` - Styling
- `script.js` - Task functionality
- `.gitignore` - Files excluded from Git
- `.github/workflows/ci.yml` - Automation workflow
